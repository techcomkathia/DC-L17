Componentes e ícones

Peças prontas (menus, cartões, formulários, janelas…) montadas com as classes da Aula 1, mais os ícones do Bootstrap Icons.

0O que é um componente?

Na Aula 1 cada classe fazia uma coisa. Um componente é um conjunto de HTML + classes que forma uma peça inteira de interface. A receita é sempre:

  1. abrir a documentação e achar o componente;
  2. copiar o exemplo;
  3. trocar os textos e ajustar com as classes utilitárias que já conhecemos.
Alguns componentes se mexem (abrem, fecham, deslizam): navbar no celular, accordion, modal e carousel. Eles precisam do JavaScript do Bootstrap (bootstrap.bundle.min.js) no fim do <body>. Quem liga o botão ao componente são os atributos data-bs-toggle e data-bs-target: não precisamos escrever JS.

1Ícones: Bootstrap Icons

O Bootstrap Icons é uma biblioteca separada com mais de 2.000 ícones gratuitos. Para usar, adicione mais um link no <head>:

<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">

Depois, cada ícone é uma tag <i> com a classe bi + bi-nome-do-icone. Os nomes estão em icons.getbootstrap.com.

O ícone se comporta como texto: muda de tamanho com fs-* e de cor com text-*.

Ícones combinam muito bem com botões e links:

Quando o botão tem só o ícone, coloque um aria-label descrevendo a ação. Quem usa leitor de tela não vê o desenho.

2Navbar (barra de navegação)

O menu do topo do site. No celular ele vira um botão "hambúrguer" que abre e fecha.

  • navbar-expand-lg: a partir de lg o menu fica aberto; abaixo disso, vira hambúrguer;
  • navbar-brand: o logo / nome do site;
  • navbar-toggler: o botão hambúrguer. O data-bs-target aponta para o id do que vai abrir;
  • collapse navbar-collapse: a parte que se esconde no celular;
  • ms-auto na lista empurra os links para a direita.

5Formulários

As classes principais:

  • form-label no <label>;
  • form-control em <input> e <textarea>;
  • form-select no <select>;
  • form-check + form-check-input + form-check-label em checkbox e radio;
  • input-group para "grudar" um ícone ou texto no campo.

Entrega

O for do label tem que ser igual ao id do campo. Assim, clicar no texto coloca o cursor no campo (e o leitor de tela sabe qual é o nome dele).
