Bootstrap 5 · Aula 1

Fundamentos e classes utilitárias

Como o Bootstrap funciona, como montar layouts com o grid e como estilizar qualquer elemento só com classes, sem escrever CSS.

0O que é o Bootstrap?

O Bootstrap é uma biblioteca de CSS (com um pouco de JavaScript). Alguém já escreveu milhares de regras de CSS e deu um nome para cada uma: são as classes. Em vez de escrever o CSS, a gente só coloca o nome da classe no HTML.

Sem Bootstrap (CSS escrito por nós)

<style>
  .aviso {
    background: #d1e7dd;
    color: #0f5132;
    padding: 16px;
    border-radius: 6px;
  }
</style>
<div class="aviso">Salvo!</div>

Com Bootstrap (só classes)

<div class="alert alert-success">
  Salvo!
</div>
Ideia principal da aula: cada classe faz uma coisa pequena (p-3 = espaço interno, text-center = centraliza o texto…). A gente combina várias classes no mesmo elemento para chegar no visual que quer.

1Como colocar o Bootstrap na página

O jeito mais simples é pelo CDN: um link para os arquivos do Bootstrap que já estão na internet. São duas linhas:

  • o CSS vai no <head>;
  • o JavaScript vai no fim do <body> (é ele que faz menus abrirem, modais aparecerem etc. Veremos na Aula 2).
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha página</title>

  <!-- 1. CSS do Bootstrap -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>

  <h1 class="text-primary">Olá, Bootstrap!</h1>

  <!-- 2. JavaScript do Bootstrap (sempre no final do body) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
Não esqueça da tag <meta name="viewport">. Sem ela, o celular não entende o layout responsivo e a página aparece "miniatura".

Se quiser escrever o seu próprio CSS também, coloque o seu arquivo depois do Bootstrap, assim as suas regras ganham quando houver conflito.

3Sistema de grid (linhas e colunas)

O grid divide a largura em 12 partes. A estrutura é sempre a mesma:

.container .row .col

O número diz quantas das 12 partes a coluna ocupa. A soma da linha deve dar 12.

4Espaçamento: margin e padding

O nome da classe é montado com 3 pedaços: propriedade + lado + tamanho.

Propriedade

m = margin (fora)
p = padding (dentro)

Lado

t topo · b baixo · s início (esquerda) · e fim (direita) · x esquerda e direita · y cima e baixo · (nada) todos

Tamanho

0 · 1 · 2 · 3 · 4 · 5 · auto

Exemplos: mt-3 = margem no topo tamanho 3 · px-4 = padding nas laterais tamanho 4 · mb-0 = tira a margem de baixo · mx-auto = centraliza um bloco.

p-1
p-3
p-5
px-5 py-2
mx-auto w-50 (centralizado)
Também dá para usar breakpoint: p-2 p-md-5 = pouco espaço no celular e bastante a partir do tablet.

5Cores de texto e de fundo

O Bootstrap tem um conjunto de cores com nomes que indicam a intenção:

text-primary: cor principal

text-secondary: secundária

text-success: sucesso

text-danger: erro, perigo

text-warning: atenção

text-info: informação

text-body-secondary: texto mais apagado

Para fundo, troque text- por bg-. A classe text-bg-* já escolhe uma cor de texto que dá para ler em cima do fundo.

bg-primary text-white
text-bg-warning
text-bg-dark
bg-danger-subtle text-danger-emphasis

6Tipografia

display-4: título de destaque

Um parágrafo com cara de h3 (classe h3)

lead: parágrafo de introdução, um pouco maior.

fs-5: tamanho de fonte (fs-1 é o maior, fs-6 o menor)

fw-bold: negrito

fw-light: fino

fst-italic: itálico

text-uppercase: tudo maiúsculo

text-center: centralizado

text-end: alinhado à direita

text-decoration-underline: sublinhado

Use a tag certa pelo significado (h1, h2…) e a classe para o tamanho. Ex.: um <h2 class="h4"> continua sendo um subtítulo, só que menor.

7Display e Flexbox

7.1 Mostrar e esconder

d-none esconde, d-block mostra. Com breakpoint dá para esconder só em algumas telas.

Só aparece no celular (d-md-none)

Só aparece do tablet para cima (d-none d-md-block)

7.2 Flexbox

d-flex coloca os filhos lado a lado. Depois a gente alinha:

  • justify-content-*: no sentido da linha (start, center, end, between, around);
  • align-items-*: no outro sentido (start, center, end);
  • gap-*: espaço entre os filhos;
  • flex-column: empilha; flex-wrap: deixa quebrar linha.
