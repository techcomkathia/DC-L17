Oi, eu sou o Claude!

O que sou Sou o Claude, um assistente de IA criado pela Anthropic. Consigo conversar, escrever, analisar dados, programar, pesquisar na web e criar arquivos (documentos, planilhas, apresentações), além de manter memória entre conversas para dar continuidade ao que já discutimos.

Onde estou disponível Além deste chat (web, desktop e app mobile), também dou acesso via API/Claude Platform para quem desenvolve produtos, via Claude Code (ferramenta de codificação agêntica pelo terminal ou apps), e via extensões como Claude para Chrome, Claude para Excel/PowerPoint e integração com Microsoft 365.

Principais usos Sirvo bem para redação e edição de textos, resumo e análise de documentos, programação e depuração de código, pesquisa e organização de informação, planejamento de estudos ou projetos, e automação de tarefas repetitivas através de agentes e conectores com outras ferramentas.

Planos e preços

  • Free — $0/mês Chat no web, desktop e mobile. Modelos Sonnet e Haiku. Busca na web, criação de arquivos, execução de código, memória entre conversas e Artifacts. Até 5 projetos.
  • Pro — $17/mês (anual) ou $20/mês (mensal) Tudo do Free, mais: uso ampliado, acesso ao modelo Opus, Claude Code, Claude Design/Slides/Docs, Claude Science, projetos ilimitados e integração com Chrome e Microsoft 365.
  • Max — a partir de $100/mês Tudo do Pro, mais: escolha entre 5x ou 20x mais uso que o Pro, limites de saída maiores, acesso antecipado a novos recursos e prioridade em horários de pico. (O nível 20x sai por $200/mês.)
  • Team — $20/pessoa/mês (anual) ou $25/mês (mensal), assento Standard; $100–125/pessoa/mês no Premium
  • Tudo do Pro, mais: administração centralizada, SSO, controles de admin para conectores, busca corporativa e sem treinamento de modelo com seus dados por padrão. Para equipes de 2 a 150 pessoas.
  • Enterprise — $20/assento/mês + uso cobrado nas tarifas da API
  • Tudo do Team, mais: controles de gasto por usuário/organização, SCIM, logs de auditoria, API de compliance, retenção de dados customizada e opção HIPAA. Cobrança anual, com atendimento self-serve ou por vendas.
